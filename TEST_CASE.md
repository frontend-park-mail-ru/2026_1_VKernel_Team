# Тесткейсы для проверки работы Refresh Token

## Предусловия
- Приложение запущено и доступно по адресу
- Пользователь авторизован
- Открыты DevTools (F12)

---

## TC-1: Базовое обновление токена при 401

### Шаги:
1. Открыть DevTools → Application → Cookies
2. Найти cookie с токеном доступа (`token`)
3. Дождаться или совершить любой API запрос
4. В Network вкладке увидеть запрос
5. Повторить запрос несколько раз

### Ожидаемый результат:
- Первый запрос выполняется успешно (200)
- Если получен 401 - автоматически отправляется запрос на `/auth/refresh`
- После обновления токена исходный запрос повторяется
- Пользователь остается авторизованным

---

## TC-2: Удаление токена через DevTools (имитация истечения)

### Шаги:
1. Открыть DevTools → Application → Cookies
2. Найти токен доступа
3. **Удалить токен полностью** (или заменить на невалидный)
4. Совершить любой API запрос (например, получить профиль, загрузить объявления)
5. Наблюдать в Network вкладке поведение

### Ожидаемый результат:
- Запрос вернет 401 (Unauthorized)
- Автоматически отправится запрос на `/auth/refresh`
- Если refresh успешен - получен новый токен
- Исходный запрос повторяется с новым токеном
- Все данные загружаются корректно

---

## TC-3: Некорректный refresh token

### Шаги:
1. Открыть DevTools → Application
2. Найти refresh token
3. **Заменить refresh token на невалидное значение**
4. Удалить или испортить access token
5. Совершить любой API запрос

### Ожидаемый результат:
- Запрос вернет 401
- Система попытается обновить токен через `/auth/refresh`
- Запрос на refresh вернет 401/403 (так как refresh token невалиден)
- Пользователь будет перенаправлен на страницу логина
- Появится сообщение об ошибке аутентификации

---

## TC-4: Множественные одновременные запросы при истечении токена

### Шаги:
1. Открыть DevTools → Network
2. Удалить access token
3. **Быстро совершить 3-5 запросов подряд** (например, загрузить разные страницы/данные в тайм)
4. Наблюдать в Network вкладке

### Ожидаемый результат:
- Все запросы получают 401
- К серверу отправляется **только ОДИН запрос на `/auth/refresh`** (не 3-5!)
- Остальные запросы ждут результата первого refresh
- После успешного refresh все запросы повторяются с новым токеном
- Нет дублирования запросов на refresh

---

## TC-5: Регистрация и логин - не должны триггерить рефреш

### Шаги:
1. Открыть DevTools → Network
2. Перейти на страницу регистрации
3. Совершить регистрацию `/auth/register` с неправильными данными (получить 401)
4. Проверить Network
5. Повторить для логина с неправильными credentials

### Ожидаемый результат:
- При 401 на `/auth/register` или `/auth/login` **рефреш НЕ запускается**
- Ошибка возвращается пользователю как есть
- Нет попыток обновить токен (так как его еще нет)

---

## TC-6: Обновление страницы после испорченного токена

### Шаги:
1. Авторизоваться, открыть какую-то страницу (профиль, объявления)
2. Открыть DevTools → Application
3. Удалить access token (оставить refresh token нетронутым)
4. Обновить страницу (F5 или Ctrl+R)
5. Наблюдать поведение

### Ожидаемый результат:
- При загрузке страницы запросы получат 401
- Автоматически запустится refresh токена
- После успеха - данные страницы загрузятся корректно
- Пользователь не увидит ошибок, запрос будет прозрачным

---

## TC-7: Проверка логирования и ошибок

### Шаги:
1. Открыть DevTools → Console
2. Повторить TC-2 (удалить токен и совершить запрос)
3. Взглянуть на консоль

### Ожидаемый результат:
- При ошибке refresh в консоли видно сообщение: `"Ошибка обновления токена: ..."`
- Сообщения содержат полезную информацию для отладки
- При успешном refresh - нет ошибок в консоли

---

## Чек-лист для успешного прохождения:

- [ ] TC-1: Токен обновляется автоматически
- [ ] TC-2: Удаленный токен восстанавливается через refresh

- [ ] TC-7: Логирование информативное

## Полезные команды для DevTools

### Удалить все cookies:
```javascript
// В консоли DevTools
document.cookie.split(";").forEach(function(c) {
  document.cookie = c.replace(/^ +/, "").replace(/=.*/, "=;expires=" + new Date().toUTCString() + ";path=/");
});
```

### Посмотреть текущий токен:
```javascript
// В консоли DevTools
(document.cookie);
// или если в localStorage
(localStorage.getItem('token'));
```

### Испортить токен:
```javascript
// В консоли DevTools
document.cookie = "token=invalid_token_xyz; path=/";
```
